# Security

## Reporting a vulnerability

Please email **security@marketmage.io** with what you found and how to reproduce it. **Never report a vulnerability in a public issue**, and never paste API tokens or other secrets into an issue.

Security reports are acknowledged within **one business day**, and we keep you updated until it's fixed.

Each repository's own `SECURITY.md`, where there is one, describes its scope and threat model. The plugin's is in [MarketMage/plugin](https://github.com/MarketMage/plugin/blob/main/SECURITY.md).
